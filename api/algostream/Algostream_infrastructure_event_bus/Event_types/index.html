Module Algostream_infrastructure_event_bus.Event_types

Event-bus types: priority bands, payloads, and the Event.t record.

All types derive bin_io for fast wire/log serialization and sexp for debugging. Domain types (Trade.t, Order.t, Tick.t) are intentionally NOT used directly here so that the domain layer stays free of ppx_jane; convert at the boundary using the helpers exposed in Event.payload.
