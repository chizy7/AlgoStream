Module Algostream_pairs.Spread

Spread tracker: s_t = y_t − β·x_t − α, with rolling mean / std / z-score.

Mean and variance use the existing Rolling_mean / Rolling_var primitives — the periodic-recompute trick keeps long-running std-devs from drifting due to floating-point cancellation.
