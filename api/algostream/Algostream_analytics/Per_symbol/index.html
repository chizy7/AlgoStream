Module Algostream_analytics.Per_symbol

Per-symbol analytics state.

Owned and mutated exclusively by the Analytics Domain. Cross-Domain reads obtain a consistent immutable Snapshot.t via snapshot.

type t
val create : symbol:string -> config:Config.t -> t
val on_tick : t -> Tick_event.t -> unit

Sole writer entry point. Runs the outlier pipeline, updates filters / rolling stats / volatility / regime, and republishes a Snapshot.t when the throttle allows.

val snapshot : t -> Snapshot.t

Lock-free, race-free read for cross-Domain consumers.

val snapshot_atomic : t -> Snapshot.t Stdlib.Atomic.t

Underlying atomic cell — exposed for Processor to hand out across Domains so reads stay O(1) without going through the symbol map.
