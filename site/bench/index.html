continuous benchmarks

Every push to main runs the full bench suite on GitHub-hosted runners and appends one point per metric. Lower is better throughout, except the two throughput metrics marked ↑ higher is better. Click any point to open the commit that produced it. Deltas compare against the previous run only — these are shared runners, so a swing of tens of percent is ordinary variance. Read the trend, not the step.
